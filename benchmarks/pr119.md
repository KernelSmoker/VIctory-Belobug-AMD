Independent CPU decoder measurements on an i9-11900K, Bazzite 45, Rust 1.98.1 release, comparing the baseline cited in this PR (01aadd1) with head 0588225. I used the existing synthetic bcpack_throughput test, whose function body is identical in both revisions. Run order was base, head, head, base, base, head in one Fedora container. Medians of three runs per revision, in MB of output per second:

| Format | Baseline | PR |
| --- | ---: | ---: |
| BC1 | 73.4 | 147.3 |
| BC4 | 74.7 | 144.3 |
| BC7 | 42.5 | 80.5 |

The synthetic workload uses 16,384 blocks per format and 40 timed decodes per run. On this host the decoder throughput improved for all three formats. The victory-formats library tests at head also completed with 28 passed and 5 ignored. Gameplay FPS was outside this measurement.
